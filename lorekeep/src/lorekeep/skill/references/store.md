# The Store: its files and the Provenance of a Version

A Store is one flat folder per Project, named by `LOREKEEP_STORE`. A Version or an Original is
written once and never rewritten or deleted; a page that changed upstream gets a new Version beside
the old one. Read the files freely; write only through `lorekeep get` and `lorekeep add`.

## Files

| File                        | What it is                                                                     |
| --------------------------- | ------------------------------------------------------------------------------ |
| `<host>--<path>--<sha8>.md` | a **Version**: Provenance frontmatter, then the Markdown body                  |
| `<stem>.orig.<ext>`         | its **Original**, the bytes received (`.html`, `.pdf`, `.json`, …); none for a Twin |
| `owner--<slug>--<sha8>.md`  | a Version the owner added with `lorekeep add`                                  |
| `tags.csv`                  | `url,tag,added_at` — which guide's Runs read which Source                      |
| `checks.csv`                | `url,checked_at,result,status,sha256` — every Recheck                          |
| `aliases.csv`               | `alias,url,added_at` — an address that redirected to a Source stored under another `url` |
| `citations.csv`             | `work_id,url[,as_of]` — written by the Project, never by lorekeep (below)      |
| `withdrawals.csv`           | `url,recorded_at,action,reason` — the owner's withdrawals and their undoing (below) |
| `datapackage.json`          | a Frictionless description of the Store, regenerated by `backup`               |
| `lorekeep.toml`             | the Project's settings: `bucket`, `freshness_days`, `[[hosts]]` rules          |
| `sources.db`                | the **Index** (SQLite), rebuilt from the files whenever needed                 |
| `.cache/readings/<stem>.md` | the **Reading** of the Version `<stem>.md`, rebuilt whenever its rules change (below); never backed up |
| `.lorekeep.lock`            | the lock that serialises writers                                               |

In a Version's name, `<path>` is the URL path with `/` and unsafe characters turned into `-`, cut
to keep the name under 200 bytes; `<sha8>` is the first 8 hex digits of the body's `sha256`; the
*stem* is the name without `.md`. Versions of one page share `<host>--<path>--` and differ in
`<sha8>`. The Latest Version is the one the latest `checks.csv` row for the `url` names, else the
newest `fetched_at`; `lorekeep get` returns it, so never pick among the files by hand.

## Frontmatter

```yaml
---
url: "https://genai.owasp.org/llmrisk/llm062025-excessive-agency"
fetched_at: "2026-10-17T17:12:19Z"
sha256: "dc01127ee6913f61ac72277830e523f8497a96559b091622cf618e7d7651720c"
publisher: "genai.owasp.org"
authority: "third-party"
converter: "trafilatura 2.3.1"
last_modified: "Sat, 17 Oct 2026 15:24:19 GMT"
title: "LLM06:2025 Excessive Agency"
canonical: "https://genai.owasp.org/llmrisk/llm06-sensitive-information-disclosure"
original:
  url: "https://genai.owasp.org/llmrisk/llm062025-excessive-agency/"
  mediatype: "text/html"
  sha256: "5f460bcc46b74107d49e6a4b9ea1829266ccd4a89f9bda4a435e10aab81f0df2"
  stored: true
origin: "web"
---
```

Every value is a quoted string (`warnings` a list of them); a field without a value is absent.

- `url` — the address the page was served at: the final one after redirects and meta refreshes,
  normalised (lower-case host, no fragment, no tracking parameters, sorted query, no trailing
  slash) and Twin-reduced (a Twin's address becomes its page's, a raw GitHub file its `blob/`
  page). Cite this. An owner-added Source has `owner:<slug>`.
- `canonical` — the address the page declares as canonical (`<link rel="canonical">`, a Twin's
  `canonicalUrl`), normalised, when it differs from `url`. Recorded, never used as `url`:
  publishers name the wrong page (this one names the 2023 risk) or a pinned release.
- `fetched_at` — when this Version was received, UTC ISO 8601.
- `sha256` — the hash of the Markdown body; its first 8 hex digits name the file.
- `publisher`, `authority` — as the host rules gave them when this Version was fetched; never
  rewritten. `get`, `search` and `status` use the effective ones, from the current rules; `get
  --json` shows the stored one beside it as `captured_authority` when they differ.
- `converter` — what made the Markdown:
  - `md-twin` — the publisher's own Markdown, as published.
  - `raw-twin` — a GitHub file read from its raw address: Markdown as published, any other file
    as `# <path>` and one fence named by its extension.
  - `verbatim` — JSON, YAML, plain text, CSV or XML as received, in one fence.
  - `trafilatura <version>` — static HTML, main content extracted.
  - `markitdown <version>` — a PDF.
  - `trafilatura <version> via crawl4ai <version>` — a page the browser rendered.
  - `owner` — a file added with `lorekeep add`.
- `etag`, `last_modified` — the server's validators, used for conditional Rechecks.
- `title` — the page's title: an HTML page's `<h1>` when its `<title>` begins with it (`helm
  rollback` of `helm rollback | Helm`), else the `<title>`, else the first heading; a Twin's own
  `title`, else its first heading; a PDF's from its metadata, else its first non-empty line.
- `modified` — the publisher's own last-modified date, `YYYY-MM-DD`, when it gives one.
- `original` — the bytes the Markdown came from: `url` (the address they came from, such as the
  Twin's or the raw file's), `mediatype`, `sha256`, and `stored` (`true` when `<stem>.orig.<ext>`
  is beside the Version; `false` for a Twin, whose Markdown is the text received).
- `origin` — `web`, or `owner` for a Source added with `lorekeep add`.
- `warnings` — what the conversion knowingly lost, one line each, written once with the Version:
  `["1 code blocks / 0 tables of the page are missing from the Markdown"]`, or `["the Markdown
  holds 14% of the page's main text"]` (under a fifth of the text of the page's `<main>`,
  `role=main` or `<article>`, its navigation left out). `lorekeep get` prints each as
  `lorekeep: warning: <url>: <warning>` on every return of the Version. Absent when nothing was
  lost, and on every Version stored before the field existed.

Nothing that changes later is read from the frontmatter: Tags are rows of `tags.csv`, Rechecks
rows of `checks.csv`, and the effective `publisher` and `authority` come from the current host
rules.

## What `--json` adds

`get --json` and `add --json` print the frontmatter's `url`, `sha256`, `fetched_at`, `converter`,
and:

- `publisher` — who authored the content, by the current host rules; the host itself when no
  rule knows it.
- `authority` — how far to rely on it for a fact, by the current host rules:
  - `primary` — a publisher documenting its own product or specification, or a law or standard
    on its official journal ([reading.md](reading.md#what-to-cite)); cite it.
  - `official` — the publisher's other material (blog, announcements); cite with care.
  - `third-party` — anyone writing about someone else's product, or a host no rule knows;
    context, not a citation.
  - `generated` — produced by an LLM and added by the owner; never cite it.
- `captured_publisher`, `captured_authority` — the frontmatter's, only when the current rules
  say otherwise. An owner's Source keeps its own: no host rule describes it.

- `path` — the absolute path of the file to read: the Version's Reading when it has one, else the
  Version.
- `version` — with a Reading only: the Version's absolute path, the evidence. Every other field
  is the Version's.
- `asked` — the command's argument exactly as given: for `get` the address with its `#fragment`,
  which no other field keeps; for `add` the file.
- `requested_url` — the address asked, normalised; it differs from `url` after a redirect or a
  Twin reduction. `add` has none of its own: it equals `url`.
- `verified_at` — the last `unchanged` Recheck, else `fetched_at`.
- `outcome` — what this call did: `stored` (first fetch), `fresh` (returned without a request),
  `unchanged`, `changed` (a new Version, the one returned), `gone` or `error` (the stored Version,
  with a warning), or `skipped` (a browser-rendered Version, never rechecked).

`search --json`: `line` is the matching line, `heading_line` the Section's heading (`null`, with
`heading` `""`, before the first heading); `other_tags` is `0` when the scope is everything;
`"relaxed": true` comes with the note line.

```json
{"results": [{"file": "/…/store/.cache/readings/docs.nvidia.com--nemo-guardrails-latest-configure-guardrails-guardrail-catalog-jailbreak-protection--96543394.md", "line": 39, "heading_line": 14, "heading": "Jailbreak Protection > Jailbreak Detection", "snippet": "…server_endpoint: \"http://0.0.0.0:1337/heuristics\" [length_per_perplexity_threshold]: 89.79 prefix_suffix_perplexity_threshold: 1845.65 ``…", "url": "https://docs.nvidia.com/nemo/guardrails/latest/configure-guardrails/guardrail-catalog/jailbreak-protection", "tag": ["nvidia"], "publisher": "nvidia", "authority": "primary"}], "other_tags": 0}
```

`status --json`:

```json
{"versions": 5, "sources": 5, "tags": {"nvidia": 5}, "oldest_fetched_at": "2026-10-17T20:08:26Z", "newest_fetched_at": "2026-10-17T20:08:26Z", "checks": {"unchanged": 0, "changed": 0, "gone": 0, "error": 0}, "unknown_hosts": ["genai.owasp.org", "helm.sh"], "readings": 1, "withdrawn_sources": 0, "withdrawn_versions": 0, "rules": 6, "bytes": 303355, "browser": {"ready": true, "crawl4ai": "0.9.5", "detail": "Chromium starts", "fix": null}}
```

## Readings

A **Reading** is a Version's Markdown after the Project's reading rules (`[[readings]]`, see
[curating.md](curating.md#lorekeeptoml)): the publisher's banner or menu dropped, a site suffix cut from
the first heading, a heading inserted before each article of a law. A rule only drops whole lines,
cuts that suffix or inserts a heading line, and never touches a line inside a code fence or a
table line, so every other line of a Reading is a line of its Version, byte for byte. `lorekeep
get` builds the Reading it returns when it is missing or stale; a Version no rule changes has
none, and `get` returns the Version itself. The Index searches a Version's Reading where it has
one, so the `file:line` of a `search` hit is in the Reading `get` returns; a change of the rules
makes the Index stale, and the next `search` rebuilds the Readings and then the Index.

```yaml
---
url: "https://docs.nvidia.com/nemo/guardrails/latest/about-nemo-guardrails-library/rail-types"
version: "docs.nvidia.com--nemo-guardrails-latest-about-nemo-guardrails-library-rail-types--c0162b5b.md"
sha256: "…"
rules: "…"
title: "Guardrail Types"
---
```

- `url` — the Version's `url`; cite it.
- `version` — the Version's file name, beside `.cache/`: the evidence.
- `sha256` — the hash of the Reading's body (the Version's `sha256` hashes the Version's).
- `rules` — the hash of the rules applied; a Reading whose rules changed is stale and rebuilt.
- `title` — the Version's `title`, with its suffix cut by a `strip_title_suffix` rule; the
  Reading's first heading (an inserted one included) when the Version has no `title` or a rule
  removed its first heading (EUR-Lex's `# Need help?` box).
- `warnings` — `rule <name> removed N lines (accepted at M lines)` (`N%` and `M%` for a
  `drop_lines` rule) for each rule the over-removal guard held back from this Version: the
  Reading was built without it. Absent when there is none.

## Rechecks

A `checks.csv` row has `result` `unchanged`, `changed`, `gone` (`404`, `410`, or a page that now
ends at its site's home page) or `error`; `status` is the HTTP status, or the exception's class
name (`ReadTimeout`) when there was no response; `sha256` names the Version that is latest after
the check. A Version's age, for the freshness window, counts from the later of its `fetched_at` and
its last Recheck.

## Withdrawals

The owner withdraws a Source stored by mistake (a parked domain, a redirect to another site, a
namesake) with `lorekeep withdraw`, which appends a `withdrawals.csv` row with `action` `withdraw`;
`withdraw --undo` appends one with `action` `undo`. The last row of a `url` decides, and a
withdrawal covers every Version of the Source. Its files stay; what changes for it:

- `search` never finds it: the Index holds no Section of it.
- `get` refuses it, also when a new address redirects to it, and `add` refuses a withdrawn
  `owner:` Source: `lorekeep: error: <url> was withdrawn by the owner at <time>: <reason> …`, exit
  `1`, nothing written.
- `read` and an Index rebuild build no Reading of it; `rules sample` and `rules check` leave it out.
- `recheck` leaves it out of every scope.
- `recheck --citations` names each work citing it
  (`lorekeep: error: <work_id> cites <url>, withdrawn at <time>: <reason>`), lists none of them as
  a revisit, and exits `1`.
- `status` counts it only on its `Withdrawn:` line (`withdrawn_sources`, `withdrawn_versions`).
- `tag add` never tags it: a `URL` names the withdrawal on stderr, a `--prefix` leaves it out.

## `citations.csv`

Written by the Project (one row per Citation of a finished work), read by
`lorekeep recheck --citations`, never written by lorekeep.

```csv
work_id,url,as_of
guides/cca/subagents,https://claude.termidy.com/learn/ccar-f/agentic-architecture/coordinator-and-subagents,2026-10-16
```

- The header `work_id,url[,as_of]` is required; without it no row is read and a warning names
  line 1.
- One row per `(work_id, url)`.
- `as_of` is when the work was written: an ISO date, read as the end of that day UTC, or an ISO
  timestamp (UTC when it names no zone). Without it, the work counts as written from the oldest
  Version.
- `url` is normalised, Twin-reduced and taken through `aliases.csv` like a `get`, so a work may
  cite the address it was given.
- A row that cannot be read is skipped with a warning naming its line.
- A cited `url` with no Version is a warning of `recheck --citations`
  (`<work_id> cites <url>, which is not stored`).
- A cited `url` the owner withdrew fails the command ([Withdrawals](#withdrawals)).

## Host rules

Two layers of rules, matched on `host/path` by longest prefix: the default table shipped in the
package and the `[[hosts]]` of the Store's `lorekeep.toml`; `lorekeep status --rules` prints the
merged table. A host matched by neither gets `publisher = <host>`, `authority = third-party`, and
the unknown-host warning. A rule's `publisher` and `authority` reach every stored Version at once;
its `twin`, `browser` and `cut` apply to new fetches only (how a page is obtained, not how it is
judged). Writing rules: [curating.md](curating.md#lorekeeptoml).

### Twins

A rule's `twin` names how its host serves Markdown beside a page:

- `md-suffix` — `<page>.md` (with `page_suffix`, that suffix replaced: `page.html` → `page.md`);
  `text/markdown`, or `text/plain` that is not HTML. Fern, Mintlify, Anthropic, AWS. The
  Version's `url` is the page's address as asked, with or without `page_suffix`: under
  `page_suffix = "/modelcard"`, `<model>` and `<model>/modelcard` both read `<model>.md` and each
  is stored under the address asked (after a redirect, the page redirected to, in that form).
- `accept-header` — the page's address with `?accept=text/markdown`. Microsoft Learn.
- `raw` — the address is its own Twin (`raw.githubusercontent.com`).
- `github-raw` — `github.com/<owner>/<repo>/blob/<ref>/<path>` is read from
  `raw.githubusercontent.com/<owner>/<repo>/<ref>/<path>` and stored under the `blob/` address.

A Twin that answers anything else (`404`, HTML) falls through to the page itself. So does a
Twin's not-found page, which is never a Version: a `200` whose first `# ` heading is `Page Not
Found` or `404` (any case) in under 40 lines, as Fern answers for a page that moved; a Recheck
that receives one records `error` and keeps the Version. When the page then redirects to an
address whose rule names an `md-suffix` or `accept-header` Twin, that Twin is read in place of the
page's HTML, and the Version is stored under the new address with the old one as its alias. The
order: the Twin of the address asked, the page, the Twin of the address it redirected to, the
page's HTML, the browser.
