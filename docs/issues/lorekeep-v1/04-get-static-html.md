# 04: `get` extracts static HTML

**What to build:** When no Twin exists, or a Twin URL answered something other than Markdown, `get` fetches the page URL over plain HTTP, follows HTTP redirects and `<meta http-equiv="refresh">` stubs, and for a `text/html` response extracts the main content with Trafilatura (formatting, links, tables on, the final URL passed as `url` so links come out absolute), takes `<link rel="canonical">` (normalised) as `url` when present with an `aliases.csv` row from the asked address, stores the received HTML as the Original (`<stem>.orig.html`, `original.stored: true`, `original.sha256` of the bytes) and records `converter: trafilatura <version>`. The step is chosen by the response's media type, never by the URL. An extraction that yields no text is reported as "no content" and stores nothing; ticket 06 turns that into the browser step.

## Comments

2026-10-17 — Decisions made while building this ticket. (1) As ticket 05 asked, HTML is a converter of its `PageStep`, not a second step that fetches the page again: `CONVERTERS` maps `text/html` and `application/xhtml+xml` to `cascade/html.py`'s `convert_html`, and a converter now takes `(received bytes, address, charset)` so HTML resolves links and decodes by the response's charset (`convert_pdf` ignores the two). `Converted` gained `canonical`: `<link rel="canonical">`, read before links are rewritten, which `PageStep` passes on as `final_url` for `get` to normalise and store under. (2) `PageStep` sends the address as given, or, when a Twin address was given (`….md`, `?accept=text/markdown`), the page address `twin.page_url` builds from it, so `get ….md` on a host whose `.md` answers HTML still reaches the page. It follows `<meta http-equiv="refresh">` in an HTML response for up to 5 hops before any conversion; `original.url`, `etag` and `last_modified` come from the response whose bytes are stored, and the stub's address becomes an `aliases.csv` row through `get`'s existing alias rule. (3) Links are made absolute with lxml (`make_links_absolute`, honouring `<base>`) and the tree is handed to Trafilatura, because Trafilatura's `url=` resolves only against scheme and host; the synthesised fixture `relative-links.html` pins it. (4) The body is Trafilatura's Markdown stripped, with one trailing newline; no `title` is mined from HTML (optional in the spec); `converter` is `trafilatura <importlib.metadata version>`. (5) The reasons ticket 06 keys on are `no content: <url> yielded no text` (or `is empty`) and `<url> answered 403`/`429`; `Fallthrough` still carries only `reason`.
