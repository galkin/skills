# The Store: its files and the Provenance of a Version

A Store is one flat folder per Project, named by `LOREKEEP_STORE`. Every file in it is written
once: a Version or an Original is never rewritten or deleted, and a page that changed upstream
gets a new Version beside the old one. Read the files freely; never edit, rename or delete them,
and never write into the Store except through `lorekeep get` and `lorekeep add`.

## Files

| File                          | What it is                                                                 |
| ----------------------------- | -------------------------------------------------------------------------- |
| `<host>--<path>--<sha8>.md`   | a **Version**: Provenance frontmatter, then the Markdown body              |
| `<stem>.orig.<ext>`           | its **Original**, the bytes received (`.html`, `.pdf`, …); none for a Twin |
| `owner--<slug>--<sha8>.md`    | a Version the owner added with `lorekeep add`                              |
| `tags.csv`                    | `url, tag, added_at` — which Runs read which Source                        |
| `checks.csv`                  | `url, checked_at, result, status, sha256` — every Recheck                  |
| `aliases.csv`                 | `alias, url, added_at` — an address that led to a Source stored under another `url` |
| `citations.csv`               | `work_id, url[, as_of]` — written by the Project, never by lorekeep        |
| `datapackage.json`            | a Frictionless description of the Store, regenerated by `backup`           |
| `lorekeep.toml`               | the Project's settings: `bucket`, `freshness_days`, extra host rules       |
| `sources.db`                  | the **Index** (SQLite); derived, rebuilt from the files whenever needed    |
| `.lorekeep.lock`              | the lock that serialises writers                                           |

In a Version's name, `<path>` is the URL path with every `/` and unsafe character turned into
`-`, cut to keep the name under 200 bytes, and `<sha8>` is the first 8 hex digits of the body's
`sha256`. The *stem* is the name without `.md`. Two Versions of one page share the prefix
`<host>--<path>--` and differ in `<sha8>`; which one is current is decided by the latest
`checks.csv` row for the `url`, else by the newest `fetched_at`. `lorekeep get` always returns
the current one — do not pick among them by hand.

## Frontmatter

```yaml
---
url: "https://platform.claude.com/docs/en/build-with-claude/prompt-caching"
fetched_at: "2026-10-17T14:40:37Z"
sha256: "f264876fce37ba4987c16fc10fb0f06fec6450e2a79f7858e22ecf041062a4b1"
publisher: "anthropic"
authority: "primary"
converter: "md-twin"
etag: "\"a1-twin\""
title: "Prompt caching"
original:
  url: "https://platform.claude.com/docs/en/build-with-claude/prompt-caching.md"
  mediatype: "text/markdown"
  sha256: "9776a72407f387b5c36db922ba63970e9db2b1030b883a8ac6a3aab9d655f718"
  stored: false
origin: "web"
---
```

Every value is a quoted string. The fields:

- `url` — the Source's address: the final one after redirects, or the page's canonical URL,
  normalised (lower-case host, no fragment, no tracking parameters, sorted query, no trailing
  slash), without a Twin suffix. Cite this. An owner-added Source has `owner:<slug>`.
- `fetched_at` — when this Version was received, UTC ISO 8601.
- `sha256` — the hash of the Markdown body after the frontmatter; its first 8 hex digits name
  the file.
- `publisher` — who authored the content (`anthropic`, `aws`, …); the host itself when no host
  rule names a publisher.
- `authority` — how far to rely on it for a fact:
  - `primary` — a publisher documenting its own product or specification; cite it.
  - `official` — the publisher's other material (blog, announcements); cite with care.
  - `third-party` — anyone writing about someone else's product, or a host no rule knows;
    context, not a citation.
  - `generated` — produced by an LLM and added by the owner; never cite it.
- `converter` — what made the Markdown: `md-twin` (the publisher's own Markdown, as published),
  `trafilatura <version>` (static HTML), `markitdown <version>` (PDF),
  `trafilatura <version> via crawl4ai <version>` (a page rendered by a browser), `owner`.
- `etag`, `last_modified` — the server's validators, when it sent them; used for conditional
  Rechecks.
- `title` — the page's title, when known.
- `modified` — the publisher's own last-modified date, `YYYY-MM-DD`, when it gives one.
- `original` — the bytes the Markdown came from: `url` (the address they came from, such as the
  Twin's), `mediatype`, `sha256`, and `stored` (`true` when `<stem>.orig.<ext>` is beside the
  Version; a Twin's Original is not stored because the Markdown is the text received).
- `origin` — `web`, or `owner` for a Source added with `lorekeep add`.

Nothing that changes later is in the frontmatter: a Source's Tags are rows in `tags.csv`, and
"last verified" is the last `unchanged` row of `checks.csv` (what `get --json` reports as
`verified_at`).

## Rechecks

A row of `checks.csv` has `result` `unchanged`, `changed`, `gone` (the page answered `404` or
`410`) or `error`; `status` is the HTTP status, or the exception's class name (`ReadTimeout`)
when there was no response; `sha256` is the hash of the Version that is current after the check.
A Version's age, for the freshness window, counts from the later of its `fetched_at` and its last
Recheck.

## Host rules

lorekeep knows where publishers serve a Twin and who they are from two layers of rules, matched
on `host/path` by longest prefix: a default table shipped in the package and the `[[hosts]]` of
the Store's `lorekeep.toml`, which extends or overrides it. `lorekeep status` prints the merged
table. A host matched by neither gets `publisher = <host>`, `authority = third-party`, and a
warning on every `get`.
